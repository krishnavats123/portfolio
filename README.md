## 🚀 Getting Started

Clone the repository:

```bash
git clone (https://github.com/krishnavats123/portfolio.git)
```

Navigate to the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
